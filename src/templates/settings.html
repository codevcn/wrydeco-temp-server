Settings

Khu vực cấu hình và quản lý dữ liệu hệ thống.

Khôi phục Dữ liệu (Restore)

Tải lên file ZIP backup để khôi phục toàn bộ các file đã upload. File ZIP này sẽ được giải nén trực tiếp vào thư mục uploads trên server.

Danger Zone

Nút bên dưới sẽ tải về bản sao lưu (ZIP) toàn bộ file khách hàng đã upload, sau khi tải thành công về thiết bị của bạn, hệ thống mới tiến hành xóa toàn bộ file và dữ liệu trên server.
